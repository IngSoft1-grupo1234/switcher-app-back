# swicher-app-back!

## Configuración del entorno

1. Clona el repositorio a tu máquina local:

    git clone https://github.com/IngSoft1-grupo1234/swicher-app-back.git

2. Instala las dependencias del proyecto:

    pip install -r requirements.txt


## Ejecución del servidor

1. Inicia el servidor de FastAPI:

    uvicorn app.main:app --reload

    Esto arrancará el servidor en modo de desarrollo, y podrás acceder a la API en `http://localhost/8000`.

2. Documentación interactiva de la API:

    Puedes ver la documentación de la API generada automáticamente por FastAPI accediendo a:
    - **Swagger UI**: [http://localhost/8000/docs]
